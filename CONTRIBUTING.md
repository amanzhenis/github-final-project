# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Check existing issues and pull requests to avoid duplicate work.
2. For a bug report, describe the expected behavior, actual behavior, and steps to reproduce it.
3. Fork this repository and create a descriptive branch for your change.
4. Make a focused change and test it with representative inputs.
5. Commit your changes with a meaningful message.
6. Open a pull request explaining the change and how you tested it.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are licensed under this project's Apache License 2.0.
