# github-final-project

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

## Input

- `p`: principal amount
- `t`: time period in years
- `r`: annual rate of interest (percent)

## Output

`simple interest = p * t * r / 100`

## Run

This educational sample requires Bash and `bc`.

```bash
bash simple-interest.sh
```

For example, a principal of 1000, a time period of 2 years, and an annual interest rate of 5 percent produce simple interest of 100.00.
